Zapret для линукса, работающий на основе конвертирования стратегий предназначенных для Windows.

Буду благодарен, если поможете в продвижении, поставив звездочку

**Стратегии, бинарники и листы взяты из [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)** 
## Использование

Скачать архив и распаковать в любую директорию. Или можно склонировать:
```
git clone https://github.com/LiGoZoff/zapret-windows-linux.git
```
1. Запустить файл `service.sh`
2. Выбрать нужную стратегию в пункте **`Установить стратегию`** в меню

## Краткие описания

`Service.sh` (адаптированный под линукс service.bat из [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube))

- **`Вкл/Выкл стратегию`** - запускает последнюю активную стретегию/отключает стратегию с удалением из автозагрузки
- **`Установить стратегию`** - производится установка уже сконвертированных стратегий, установка стратегии происходит через /opt/[zapret/](https://github.com/bol-van/zapret)
- **`Hастройки`**
  - **`Toggle autorun`** - включает/отключает автозагрузку активной стратегии
  - **`Toggle Game Filter (status)`** - переключение режима обхода для игр (и других сервисов, использующих UDP и TCP на портах выше 1023). В скобках указан текущий статус.
  - **`Toggle IPSet Filter (status)`** - переключение режима обхода сервисов из ipset-all.txt.
  В скобках указан текущий статус:
    -  none - никакие айпи не попадают под проверку
    -  loaded - айпи проверяется на вхождение в список
    -  any - любой айпи попадает под фильтр
  - **`Toggle Hosts (status)`** - Добавляет/Убирает строки из файлы hosts в локальный файл hosts
- **`Обноаления`**
  - **`Обновление запрета`** - проверяет на наличие обновлений и обновляет до новой версии при необходимости
  - **`Обновить Hosts и Lists`** - обновляет файлы hosts и Lists из [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)
  - **`Обновить Binaries`** - обновляет бинарные файлы *.bin из [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)
  - **`Обновить Strategies`** - обновляет стратегии из [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)
- **`Утилиты`** - пункт управления ipset и hosts файлами
  - **`Конвертация стратегий`** - происходит конвертация стратегий из папки windows-strategies формата general*.bat
  - **`Тест стратегий (полный)`** - происходит тестирование статегий из папки linux-strategies формата general*.sh и по кончание выводит таблицу и результатами теста и дает возможность сразу запустить нужную стратегию
  - **`Тест стратегий (быстрый)`** - происходит тестирование статегий из папки linux-strategies формата general*.sh, тестирование идет до первой рабочей стратегии, когда находиться рабочая стратегия она сразу же применяется

- **`Удалить Запрет`** - откатывает все примененные изменения, после чего можно спокойно удалить папку


## Решение возможных проблем

Если случилось так, что стратегия работала и перестала работать на следующий день или после перезагрузки.
Попробуйте сделать исполняемым файл /opt/zapret/ipset/create_ipset.sh и запустить его:
```
sudo chmod +x /opt/zapret/ipset/create_ipset.sh
sudo bash /opt/zapret/ipset/create_ipset.sh
```
 После включите и выключите стратегию, чтобы "перезагрузить ipset", при следующем включении стратегии все должно работать.

### Примечания

В папку windows-strategies можно вставлять другие стратегии в формате general*.bat
